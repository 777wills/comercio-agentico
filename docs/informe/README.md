# Borradores del informe

Secciones del informe escritas a medida que avanzó el trabajo, para ensamblarlas en la plantilla del curso
(`privado/curso/Formato_informe.docx`; español, citación APA 7; las referencias verificadas están en
`07_referencias.md`).

Convención de nombres: `NN_seccion_tema.md` (01 introducción, 02 estado del arte, 03 metodología, 04 resultados,
05 discusión, 06 conclusiones y hoja de ruta, 07 referencias).

Correspondencia con la plantilla: 01 + 02 → I. Introducción; 03 → II. Materiales y métodos; 04 → III. Resultados
(sin interpretación); 05 → IV. Discusión; 06 → V. Conclusiones; plan frente a lo logrado y declaración de uso de
IAG → Apéndice; 07 → Referencias.

Reglas: registro declarativo y académico, sin metacomentario; toda cifra con su fuente o con la corrida de
`resultados/` que la produjo. Los números provisionales (3.x, 4.y, Tabla 5.x.1) y las marcas `[ref: …]` se
resuelven al ensamblar.
